typescreen glyph generator

Renders a range of Unicode codepoints with an installed font into a fixed-size bitmap table, using the browser's own text renderer. Every glyph is the same width and height — this is for a monospace typewriter, not a typesetter.

Any font installed on this computer. The suggestions are all freely licensed. A generated table is a derivative of the font it was rendered from — only redistribute tables made from fonts whose licence allows it.
The grid cell. Every glyph is drawn into a box of exactly this size; the page is laid out in cells of this size.
Adjust against the preview until the widest, tallest and deepest glyphs all fit inside the red box. There is no formula for this; it depends on the font. Only leave as much whitespace as you must.
Hex or decimal, single values or ranges, comma-separated. The default is printable ASCII, Latin-1 Supplement (Western European: é ñ ü ß å ø ç …) and Latin Extended-A (œ Œ ÿ plus Central European: ł ś ž č ő ğ …). The standalone accents used as dead keys — ´ ` ¨ ^ ~ — are all inside these ranges. A glyph the font lacks is drawn with the browser's fallback font; check the preview if in doubt.
